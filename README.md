# SNOWY BALLS

Browser game: throw snowballs at a window with a two-phase freeze-the-pointer aim
(angle, then power), earn coins for accuracy and streaks, unlock characters/buffs/
projectiles. Pixel-art style, no login, progress saved via `localStorage`.

## Running locally

```
py -m http.server 8124
```

Then open http://localhost:8124.

See [docs/NOTES.md](docs/NOTES.md) for current gameplay constants and design decisions.
